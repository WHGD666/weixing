# Task Contract v0

状态：draft，等待数据审计后冻结。

## 任务

光学遥感卫星图像 25 类水平框目标检测。

## 预测时可用输入

- 输入图像本身。
- 图像尺寸和像素值。
- 推理程序可自动判断灰度/彩色和尺寸。

## 预测时禁止依赖

- 官方测试集标签。
- 人工告知图片属于舰船、飞机或发射车场景。
- 任何测试集文件名、目录、元数据中的泄漏信息。
- 训练后基于官方隐藏测试反馈反向调整并伪装成同一轮冻结模型。

## 输出

水平边界框、类别 ID、置信度。

## 当前主要风险

- 子类分类错误导致 TP 不成立。
- 训练集存在漏标和错标。
- 灰度舰船图和彩色飞机/发射车图存在域差异。
- 大图切片重复框会增加 FP。

# INF001：direct 推理 NMS 参数对照实验

状态：completed，已完成 897 张固定验证集的三组对照；暂不冻结最终推理参数。

## 实验目的

验证同一个 `EXP001` 模型在不同 Ultralytics 推理 NMS IoU 参数下的重复框、漏检、虚警和耗时变化。除 `iou` 外，模型、数据、标签版本、验证划分、置信度和输入尺寸均保持不变。

## 固定条件

| 项目 | 值 |
| --- | --- |
| 模型 | `EXP001` 的 `best.pt` |
| 标签版本 | `v0_original` |
| 验证划分 | `v1_scene_80_20` |
| 验证图片 | 897 |
| 输入尺寸 | 1024 |
| `conf` | 0.25 |
| 推理模式 | direct |
| 只改变的变量 | `iou` |

## 对照结果

| NMS IoU | 预测框数 | TP | FP | FN | Overall Recall | Overall FDR | 总耗时（秒） | 最大单图（秒） |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.70（控制组） | 4493 | 4115 | 378 | 128 | 0.96983 | 0.08413 | 39.518 | 4.385 |
| 0.60 | 4465 | 4113 | 352 | 130 | 0.96936 | 0.07884 | 26.540 | 4.750 |
| 0.50 | 4441 | 4106 | 335 | 137 | 0.96771 | 0.07543 | 26.041 | 4.154 |

三组结果均通过当前内部的整体 Recall、FDR 和普通验证图耗时检查。这里的检查不是比赛封闭测试成绩。

## 分组结果

| NMS IoU | 舰船 Recall / FDR | 飞机 Recall / FDR | 发射车 Recall / FDR |
| ---: | ---: | ---: | ---: |
| 0.70 | 0.86502 / 0.24293 | 0.98817 / 0.04695 | 0.82716 / 0.45082 |
| 0.60 | 0.86122 / 0.23350 | 0.98817 / 0.04441 | 0.82716 / 0.41228 |
| 0.50 | 0.84791 / 0.22837 | 0.98817 / 0.04340 | 0.82716 / 0.37383 |

## 结果解释

- 降低 NMS IoU 后，预测框总数、FP 和 FDR 均下降，说明它确实压制了重叠重复框。
- 代价是部分重叠目标被合并，整体 TP 减少、FN 增加；舰船 Recall 对该变化最敏感。
- 飞机 Recall 在三组中相同，说明飞机类别的主要问题不是 NMS，而是少量细分类混淆和重复框。
- 发射车 Recall 三组均为 0.82716，说明单纯调整 NMS 不能解决漏检；FDR 虽然下降，但仍明显偏高。
- 0.60 是一个中间折中点，但目前没有证据证明它优于 0.70 或 0.50 的最终选择。
- 三次耗时受首次 GPU 预热、系统状态和运行顺序影响，不能仅凭三次独立运行宣称 0.50 一定比 0.70 快；后续速度测试需要单独预热并重复测量。

## 当前决策

暂不冻结 NMS IoU。保留三组结果，后续优先测试置信度阈值对 `FSC`、`MS` 和 `QHS` 的影响；模型权重和验证协议不变。若以整体 Recall 为第一优先级，0.70 暂时占优；若以降低虚警为第一优先级，0.50 暂时占优；若需要折中，0.60 可作为候选，但必须结合下一轮测试和错误可视化决定。

## 报告可用结论

该实验可以作为一个后处理消融实验写入报告：在相同模型和数据协议下，降低 NMS IoU 能减少重复预测和虚警，但会带来一定漏检，且不能解决发射车类别的根本识别问题。因此，后续优化不能只依赖 NMS 参数，还需要结合类别不均衡、目标尺度、标签质量和类别判别能力进行分析。

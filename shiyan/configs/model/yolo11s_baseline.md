# YOLO11s Baseline Model

用途：第一版官方原始标签 baseline。

## 选择理由

- 与当前数据格式兼容：官方训练标签是 YOLO 水平框格式。
- 工程链路短：训练、验证、推理、可视化和权重导出都容易打通。
- 适合本机：RTX 4060 Laptop 8GB 显存可从 `imgsz=1024`、`batch=4` 起步。
- 适合首版提交：第一阶段目标是跑通链路和获取平台反馈，不追求一次到位。

## 风险

- 对极少样本类别 HM、LQS 的泛化能力可能弱。
- 默认验证指标不是比赛最终 Recall/FDR，需要后续实现官方口径评估。
- 10000x10000 大图需要切片推理，不能直接依赖常规单图推理。
- 若首次训练显存不足，应优先降低 batch 到 `2`，而不是降低数据管理要求。

## 后续替代候选

- `yolo11m.pt`：本机可能显存压力较大，适合在 baseline 跑通后尝试。
- `yolov8s.pt`：若 `yolo11s.pt` 下载或兼容出现问题，可作为稳定替代。
- oriented-box 或 MMDetection 方案：作为后期研究路线，不进入第一版主线。

## 对比赛实验的影响

本机适合承担：

- 数据审计和标签检查。
- YOLO baseline 训练。
- 小模型和中小模型消融实验。
- 切片推理流程验证。
- COCO JSON 输出和可视化验证。

本机不适合直接承担：

- 大模型长时间大 batch 训练。
- 以 RTX3090 为目标的最终吞吐量评估。
- 大规模多模型 ensemble 的完整训练矩阵。

## 初始训练建议

- 优先使用 YOLO 系列作为第一条主线。
- 输入尺寸从 `1024` 或 `1280` 起步。
- 使用 AMP 混合精度。
- batch size 先保守设置，稳定后再向上试。
- 大图推理必须预留切片和跨切片融合流程。
- 所有正式实验必须保存运行命令、配置、Git commit、数据指纹和指标结果。

# 光学遥感卫星陆上目标检测识别比赛项目

本仓库用于管理“基于不均衡小样本学习的光学遥感卫星陆上目标检测识别”比赛的资料、实验、代码、报告和提交材料。

当前项目的核心任务是：

```text
在小样本、类别不均衡、多源遥感图像和大图推理约束下，
完成 25 个细分类目标的水平框检测，
并按官方评分口径聚合为舰船、飞机、车辆三大类进行评测。
```

## 1. 最关键结论

后续所有实验都必须遵守以下判断：

- 任务不是简单三分类检测，而是 **25 个细分类检测**。
- 只有预测框位置正确且 **子类分类正确**，才可能计为 TP。
- 标注格式是 YOLO 水平框，最终结果需要按官方要求输出检测结果。
- 官方评估使用水平框，不要求提交旋转框。
- 测试图像尺寸不固定，最大约为 `10000 x 10000`。
- 测试时只给图像，不会告诉图像属于船、飞机还是发射车场景。
- 官方不会自动合并重复框，重复框会增加 FP。
- 训练集可能存在漏标、错标，需要自行复核修正。
- 外部数据允许使用，但必须记录来源、处理方式，并保证不使用测试集。
- 最终应准备 Docker 或统一推理入口，保证可复现、可测评。

## 2. 官方刚性指标

初赛刚性门槛：

| 指标 | 要求 |
| --- | --- |
| 召回率 | `>= 85%` |
| 虚警率/误检率 | `<= 20%` |
| 单幅 `10000 x 10000` 图像推理时间 | `<= 20 秒` |

硬件约束以官方最终通知为准，评分方案中限定为单张 NVIDIA RTX3090 或同等算力国产 GPU/NPU。

| 阶段 | 目标 |

| P1 | 数据检查、可视化、标注问题记录 |

| P3 | 跑通 25 类基线模型 |
| P4 | 修正标注，处理漏标、错标、边界目标 |

| P7 | 优化大图推理速度和封装接口 |

详细流程见 [比赛全流程实施方案与实验管理.md](docs/00_项目总方案/比赛全流程实施方案与实验管理.md)。

## 6. 实验管理原则

每次实验必须做到：

- 有唯一实验编号；
- 有明确假设；
- 有固定数据版本、标注版本、划分版本；
- 有配置文件；
- 有 Git commit 记录；
- 有 25 类细分类指标；
- 有三大类聚合指标；
- 有大图推理时间；
- 有误检和漏检案例；
- 有结论和下一步。

不要做“改了一堆参数但不知道哪个有效”的实验。后续研究报告、答辩和复盘都依赖这些记录。

## 7. 当前优先级

当前最优先的工作顺序：

1. 保持剩余两次正式提交机会不动，等待 EXP006 完整 3090/Docker 验收。

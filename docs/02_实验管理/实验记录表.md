# 实验记录表

## 1. 使用规则

每次训练、推理、阈值搜索、标注版本对比、外部数据对比、速度测试，都必须登记。

实验记录的目标不是写流水账，而是保证后续能回答：

- 这次实验想验证什么；
- 改了哪些变量；
- 使用了哪个数据和标签版本；
- 指标变好还是变差；
- 结论能否写进报告；
- 下一步应该做什么。

## 2. 实验完成判定

一个实验只有在“结果验证”和“总结分析”都完成后才算结束。每次收尾必须补齐：

- 实际运行状态、完成轮数或处理样本数；
- 使用的数据、标签、划分、代码版本和关键配置；
- 机器可读指标、耗时、模型或结果文件哈希；
- 误检、漏检、异常和数据质量问题；
- 结果解释、可比较性判断和报告可用结论；
- 下一步动作、保留或淘汰决定。

失败实验、异常测试和没有达到预期的结果同样需要总结，不能只记录成功实验。

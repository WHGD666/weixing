# 外部数据来源记录

## 1. 使用规则

官方答疑允许使用外部数据，但必须满足：

- 不使用官方测试集；
- 记录数据来源；
- 记录许可证或使用限制；
- 记录类别映射；
- 记录处理方式；
- 最终报告中说明清楚；
- 保证训练流程可复现。

## 5. 使用风险

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 类别定义不同 | 外部类别和官方 25 类不完全一致 | 建立映射规则，只使用确定类别 |
| 域差异 | 外部图像分辨率、传感器、颜色差异大 | 做归一化、增强和小规模验证 |
| 标注格式不同 | 可能是旋转框或 COCO 格式 | 统一转换为水平框 YOLO/内部格式 |
| 许可证限制 | 有些数据不能商用或再分发 | 记录许可证，不上传原始数据 |
| 噪声标签 | 外部标注可能不准 | 抽样可视化复核 |
